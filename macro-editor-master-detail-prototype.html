Master-Detail Macro Editor Prototype

Interactive mockup with multi-select deletion pattern

How to Use This Prototype

  • Click on a macro to edit it (opens in detail panel)
  • Ctrl + Click (or Cmd + Click on Mac) to select multiple macros
  • Selected macros show blue highlight and left border
  • Delete button appears at bottom when macros are selected
  • Click "New Macro" to create a new macro
  • Search filters the macro list in real-time
